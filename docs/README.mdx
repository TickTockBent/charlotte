**Charlotte** is an MCP server that gives AI agents structured, token-efficient
access to the web — a compact orientation on arrival, targeted queries for
specifics, full detail only on request. These docs cover running it, connecting
it to claude.ai, and trusting it with a public endpoint.

If you're deciding whether Charlotte is worth your time, the
[marketing page](https://charlotte-rose.vercel.app) has the demo and the
benchmark story. If you've already decided: the links below are the fast path.

## Start here

- **[Quickstart](https://charlotte.mintlify.site/)** — one command to a live claude.ai connector; the shortest honest path.
- **[Self-Hosting](https://charlotte.mintlify.site/self-hosting)** — the durable setup: your own domain, a stable token, docker compose.

## Reference

- **[Configuration](https://charlotte.mintlify.site/configuration)** — every config key, env var, and precedence rule.
