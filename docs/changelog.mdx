## Week of August 18, 2026

### New features

- **`max_height` on `charlotte_screenshot` clips long pages.** Full-page screenshots now stop at 2000 pixels by default. This keeps a single call on a very tall page from returning a multi-megabyte image that exceeds the 256 KB inline artifact cap. Set `max_height` to raise or lower the cutoff, up to the Chromium limit of `16384` to effectively disable clipping. When clipping happens, the response includes a `clipped` block reporting the original page height and the captured height. Agents can use it to decide whether to scroll and take a follow-up screenshot. Existing calls pick up the new `2000` default automatically.

    ```json
    {
      "name": "charlotte_screenshot",
      "arguments": {
        "full_page": true,
        "max_height": 4000
      }
    }
    ```
