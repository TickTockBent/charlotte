## Week of August 18, 2026

### New features

- **`max_height` on `charlotte_screenshot`.** Full-page screenshots now clip from the top when a page is taller than `max_height` (default `2000` px). This avoids Chromium's super-linear compositor cost on very long pages. When a clip happens, the response includes a new `clipped` text block alongside the image with `captured_height`, `full_page_height`, and a steering message. Callers can use it to distinguish a complete short capture from the top slice of a taller page. Existing calls pick up the new default automatically. Set `max_height: 16384` to disable clipping and always capture the full page.
